📚 Learning Management System (LMS)
This is a full-stack Learning Management System (LMS) built to provide a robust and modern online learning experience. The system allows users to register, enroll in courses, make payments, and access learning content, while giving administrators and instructors full control over course and user management.

🛠 Tech Stack
🔹 Frontend
React JS – Frontend library for building user interfaces

Tailwind CSS – Utility-first CSS framework

Axios – For making HTTP requests to backend APIs

Clerk – User authentication and session management (Sign up, Sign in, Role-based auth)

🔹 Backend
Node.js – JavaScript runtime environment

Express.js – Lightweight web framework for building APIs

MongoDB – NoSQL database

Mongoose – Object Data Modeling (ODM) library for MongoDB

🔹 Integrations & Tools
Stripe – Payment gateway for secure course purchases

Cloudinary – Cloud-based media storage for images and videos

Postman – Used for testing and documenting APIs

🚀 Features
🔐 Authentication with Clerk

Secure sign up/sign in

Role-based access (Admin, Instructor, Student)

Session handling and protected routes

🎓 Course Management

Admin/Instructor can create, update, and delete courses

Cloudinary integration for uploading course thumbnails or media

💳 Payments

Stripe integration for one-time payments

Enroll in paid or free courses

📦 API

RESTful APIs built with Express.js

Tested with Postman

Secure endpoints using middleware and Clerk auth

📡 Frontend Integration

Axios used to connect React frontend with Express backend APIs

Responsive and mobile-friendly UI built with Tailwind CSS
